# 📚 Repositório de Aulas Java - SENAI

Este repositório contém os códigos, exercícios e projetos desenvolvidos durante o curso de **Java** do **SENAI**. O objetivo é organizar o conteúdo aprendido de forma prática e acessível, servindo como material de estudo e revisão.

## 🧠 Conteúdo

- Fundamentos da linguagem Java
- Variáveis, Tipos de Dados e Operadores
- Estruturas Condicionais e de Repetição
- Métodos e Funções
- Programação Orientada a Objetos (POO)
- Coleções (Listas, Mapas, Sets)
- Tratamento de Exceções
- Entrada e Saída de Dados
- Projetos Práticos

## 🛠 Requisitos

- [Java JDK 17+](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) ou [Eclipse](https://www.eclipse.org/)
- Git
